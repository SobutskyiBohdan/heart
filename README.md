# Project Title

A brief description of what this project does and who it's for. This application is built using React, TypeScript, and Vite.

## 🛠 Prerequisites

Before you begin, ensure you have the following installed on your machine:
* [Node.js](https://nodejs.org/)

## 🚀 Run Locally

Follow these steps to get the project up and running on your local development environment:

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Run the development server:**
   ```bash
   npm run dev
   ```
3. **📦 Build for Production**
   ```bash
   npm run build
   ```
